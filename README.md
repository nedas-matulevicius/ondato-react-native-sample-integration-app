# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

The app is built with Expo SDK 57, using latest packages and modules.

This app uses custom colour schemes and fonts to show how they apply to Ondato SDK. The fonts can be found under `assets/fonts` directory, while the theme itself is in `src/ondato/theme.ts` file.

The core implementation is in `src/app/index.tsx`. `DEFAULT_VERIFICATION_ID` variable is for testing purposes, where one could copy-and-paste their own generated identity verification ID to start the flow inside the SDK.
